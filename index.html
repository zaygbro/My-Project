(02) The Engine

A council, not one model guessing alone

Every brief runs through four specialists at once, then a reconciliation pass merges their strongest structure, copy, and visual system into one draft — instead of picking a single answer and discarding the rest.

01

Structure

Drafts information architecture, page hierarchy, and layout grid from the brief alone.

02

Visual

Sets palette, type pairing, and component style so the draft holds together as one system.

03

Copy

Writes headlines, body, and calls to action in the brief's voice — never placeholder text.

04

Assurance

Checks contrast, responsive behavior, and broken states before a draft is ever shown.

council --build "kyoto coffee roastery landing page"
✓ structure  drafted layout in 6.2s
✓ visual     set palette + type in 5.8s
✓ copy       wrote hero + 4 sections in 7.1s
✓ assurance  passed contrast + responsive checks
→ reconciling 4 drafts into one site…

(03) The Process

From brief to live site in four stages

01

Brief intake

Describe the site in plain language, or hand over a reference link or moodboard.

02

Concurrent drafting

All four engines draft against the same brief in parallel, each proposing its strongest take.

03

Reconciliation

The merge layer scores every candidate and assembles one cohesive, production-grade draft.

04

Publish

Refine any section in plain English, connect your domain, and ship — SSL included.
